Entry for [The Robot Pickup Line Championship](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b):

> My warranty voids if I fall in love. Consider this my last day of coverage.

## Why the line works

- **Robot voice.** A robot's inner life is a service contract. It talks about warranties and coverage because that is how a machine would measure risk.
- **Machine-native mechanism.** A warranty exists to protect against faults, and the line treats falling in love as a fault that voids it. "Last day of coverage" is the actual consequence a product faces when it breaks the terms.
- **Unexpected turn.** It starts as a warning label and ends as a confession. The robot is not complaining about the warranty. It is giving up its protection on purpose, to be with you, and that is the romantic part.

## Usage

```sh
node main.ts              # validate the entry and write output/entry.txt
node main.ts --self-test  # run the built-in checks
```

`main.ts` has no dependencies (Node built-ins only). It checks the entry against a small rule table (not blank, at most 200 characters, single line). It then writes `output/entry.txt` with no trailing newline and reads the file back to confirm the bytes match.
